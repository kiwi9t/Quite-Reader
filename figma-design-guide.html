第一步：建文件结构

Step 1

新建 Figma 文件

  • 打开 Figma → New design file
  • 文件名命名为 Quiet Reader · Design
Step 2

建两个 Page

左下角 Pages 面板，点 + 新建页面：

  • Page 1 → 改名为 🎨 Design System
  • Page 2 → 改名为 📄 Screens
先把 Design System 建好再做 Screens，效率高很多。改名方式：双击 page 名称。

第二步：建 Design System

在 🎨 Design System 页面里操作。这个页面不需要精美排版，只是一个"系统仓库"。

2.1 建 Color Styles

你需要把颜色定义成 Figma 的 Local Styles，这样在所有 Frame 里都能复用。

操作

逐个创建颜色

  1. 用矩形工具 R 画一个小方块，填充对应颜色
  2. 选中方块 → 右侧 Fill 区域点 4个点 图标（Style）
  3. 点 + → 起名（见下方命名规则）→ 保存

颜色命名规范（建议用 color/角色 格式）：

color/bg
#F8F4EC
color/surface
#FFFDF8
color/text-primary
#2A2520
color/text-secondary
#7A6F64
color/border
#E4D8C8
color/accent
#8A6A43
color/soft-accent
#EFE3D0
color/severity-high
#9A5A3C
color/severity-medium
#B08A5A
提示： 在 Design System 页面，你可以把这些色块整齐排列当参考。但最重要的是它们被保存成了 Style，可以从右侧面板随时调用。

2.2 建 Text Styles

用文字工具 T 写一段文字，设置好字体和字号后，同样点右侧 Text → Style 图标 → + 保存。

先做这几个 Text Styles：

Text Styles 清单
名称 字体 字号 行高 用途
text/reader-body Georgia 20px 36px 正文阅读
text/ui-body Inter 15px 24px UI 正文、说明
text/card-title Inter 18px · 600 28px 卡片标题、词
text/card-body Inter 14px 22px 卡片正文
text/label Inter 13px · 500 20px 辅助说明、标签
text/page-title Inter 32px · 600 40px 页面大标题
Georgia 没有中文字形，没关系 — 正文是英文小说原文，中文只出现在卡片和 UI 里（用 Inter 即可）。如果要兼容中文正文，改用 Noto Serif SC。

第三步：做基础 Components

还是在 🎨 Design System 页面。Components 做好后，Screens 里直接拖进来，改改文字就行。

3.1 什么是 Component？

Component 是可复用的模块。做法：画好一个元素 → 选中 → ⌘ Option K（Mac）或右键 → Create component。之后拖出来的都是 Instance，改 Master 会同步更新。

3.2 Button

操作步骤

做主按钮 Primary Button

  1. 用矩形 R 画一个 160 × 44 的矩形
  2. Fill: #8A6A43（accent），Corner radius: 8
  3. 在矩形上加文字 T：Preload Chapter，字体 Inter · 15px · 600 · white
  4. 选中矩形 + 文字 → ⌘ Option K → 命名 Button/Primary
操作步骤

做次级按钮 Ghost Button

  1. 复制 Primary Button，修改 Fill 为 无，加 Stroke: #E4D8C8 · 1px
  2. 文字颜色改为 #7A6F64
  3. 命名 Button/Ghost

3.3 Input & Textarea

操作步骤

Input 输入框

  1. 矩形：宽 320 · 高 44
  2. Fill: #FFFDF8，Stroke: #E4D8C8 · 1px，Radius: 6
  3. 加 placeholder 文字（#7A6F64）放在内部，左边距 14px
  4. 加 label 文字在矩形上方，间距 8px，样式 text/label
  5. 全选 → Create component → Input/Default
Textarea 同理，高度改为 120 以上，placeholder 文字靠左上对齐。

3.4 VocabularyCard（词汇卡片）

这是最重要的 component 之一。结构：

┌──────────────────────────────────────┐ │ concede · high │ ← 词 + severity badge │ 承认，尤其是不情愿地承认 │ ← 中文释义 │ core verb │ ← 词性标签 │ ─────────────────────────────────── │ │ 为什么重要：它是句子的核心动作…… │ ← 说明 └──────────────────────────────────────┘
操作步骤

画 VocabularyCard

  1. 画矩形：宽 200 · 高 120，Fill: #FFFDF8，Stroke: #E4D8C8，Radius: 10
  2. 内边距：上下左右各 16px
  3. 第一行：左侧词（text/card-title · #2A2520），右侧 severity badge（小胶囊形，Fill: #EFE3D0，文字 text/label · #9A5A3C）
  4. 第二行：中文释义（text/card-body · #2A2520）
  5. 第三行：词性标签（text/label · #7A6F64）
  6. 分割线：1px · #E4D8C8，用矩形高 1px 做
  7. 第四行：说明文字（text/label · #7A6F64）
  8. 全选 → Card/Vocabulary

3.5 ContextCard（背景知识卡片）

┌──────────────────────────────────────┐ │ boarding school │ ← 词条 │ 英国寄宿学校常见于成长小说…… │ ← 说明 │ ─────────────────────────────────── │ │ 为什么现在有用：帮助理解学校场景…… │ └──────────────────────────────────────┘

做法类似 VocabularyCard，去掉 severity badge，左上角可加一个浅色小图标（书本/地点/人物，用 Phosphor Icons 插件）。命名 Card/Context。

3.6 InlineAnnotation

这是正文里被标注词的样式。

操作步骤

做 InlineAnnotation（低调下划线版）

  1. 文字：concede，样式 text/reader-body
  2. 在文字下方加一条 1px 高的矩形，颜色 #B08A5A（medium accent），宽度与文字对齐
  3. 可以另做一版：文字加底色 #EFE3D0，Radius: 3，不加下划线
  4. 命名 InlineAnnotation/Underline
避免：荧光黄高亮、红色下划线、粗体词 — 这些都会让注意力离开正文。

3.7 AnnotationPopover（点词后的浮层）

┌────────────────────┐ │ concede │ ← 词 │ 承认（不情愿地） │ ← 中文释义 │ ──────────────── │ │ 原句: "He had to │ │ concede defeat." │ │ severity: medium │ └────────────────────┘

画一个 220 × auto 的浮层框，Fill: #FFFDF8，Stroke: #E4D8C8，Radius: 10，底部加一个小三角指示箭头（用多边形工具）。命名 Popover/Annotation。

第四步：Frame 01 Setup 页

切换到 📄 Screens 页面，开始做正式页面。

Step 1

新建 Frame

  1. 按 F 选 Frame 工具
  2. 在右侧面板选 Custom，宽 1440 · 高 1024
  3. 双击 Frame 名，改为 01 Setup
  4. Fill: #F8F4EC
Step 2

左侧介绍区（480px 宽）

左侧内容区域（x=120, y=0, w=480, h=1024） 垂直居中于左侧 Product Name "Quiet Reader" 32px · 600 · #2A2520 Tagline "Read smoothly, without spoilers." 18px · #7A6F64 · mt-12 ──────────────────── 本章准备说明（3-4行文字） "Paste your chapter below. We'll prepare a spoiler-free vocabulary preview before you start reading." 15px · #7A6F64

用一个 Auto Layout Frame（⌘ Shift A）装左侧内容，方向 Vertical，Gap 16px。

Step 3

右侧表单区（520px 宽）

表单容器（x=800, y=0, w=520, h=1024） 背景：#FFFDF8 左侧 border: 1px · #E4D8C8 内边距 top: 80px left/right: 60px [Input] Book title [Input] Chapter title [Input] Chapter index [Input] Test score (e.g. IELTS 6.0) [Textarea] Reading difficulties [Textarea] Safe previous summary [Textarea] Chapter content ← 最高，约 200px [Button/Primary] Preload Chapter ← 底部，全宽

所有 Input 组件从 Design System 拖过来，用 Auto Layout 纵向排列，Gap 20px。

让表单"安静"的关键：输入框之间间距充足（20px+），字段 label 简短，textarea 没有滚动条感。不要加分割线或 section header，留白即分组。

第五步：Frame 02 Chapter Preload 页

Step 1

新建 Frame

同样 1440×1024，Fill: #F8F4EC，命名 02 Chapter Preload。

Step 2

页面结构

顶部 Nav Bar（h=64, bg=#FFFDF8, border-bottom:#E4D8C8） 左：Chapter title（18px · 600） 右：progress label（13px · #7A6F64） 中间内容区（max-width: 800px, 水平居中） ┌─ Non-Spoiler Preview Card ──────────────────┐ │ A QUIET INTRODUCTION （label · uppercase） │ │ 这一章，Alex 到达了新学校……（200字以内） │ └──────────────────────────────────────────────┘ Core Vocabulary（section header · label · uppercase） ┌──词卡──┐ ┌──词卡──┐ ┌──词卡──┐ │concede │ │tenure │ │aloof │ └────────┘ └────────┘ └────────┘ Safe Context（section header） ┌──背景卡────────────────┐ ┌──背景卡────────────────┐ │ boarding school │ │ prefect system │ └────────────────────────┘ └────────────────────────┘ 底部（position: sticky bottom） [Button/Primary] Start Reading →
Step 3

Non-Spoiler Preview Card

  1. 画一个全宽（800px）卡片，Fill: #FFFDF8，Stroke: #E4D8C8，Radius: 12，内边距 32px
  2. 顶部小标签：BEFORE YOU READ，13px · 500 · #8A6A43 · letter-spacing: 1px
  3. 正文：Georgia · 16px · #2A2520 · line-height 28px
Step 4

词卡和背景卡的排列

把之前做好的 Card/Vocabulary 和 Card/Context 拖进来，用一个 Auto Layout 横向排列，Gap 12px，允许 wrap（自动换行）。

词卡宽 200px，背景卡宽 380px，这样每行放 3 张词卡 / 2 张背景卡，节奏感好。

第六步：Frame 03 Immersive Reader 页

这是设计上最重要的页面，需要最多时间打磨。

Step 1

新建 Frame

1440×1024，Fill: #F8F4EC，命名 03 Immersive Reader。

Step 2

顶部 Chapter Bar（极细）

h=48px bg=#FFFDF8 border-bottom: 1px · #E4D8C8 左：Chapter 3 · The Arrival （14px · #7A6F64） 右：progress bar（宽120px · h=3px · bg:#EFE3D0 · fill:#8A6A43）

progress bar：画两个叠放的矩形，底层 #EFE3D0，上层 #8A6A43，宽度代表进度（如 40%）。

Step 3

正文阅读区（最重要）

  • 居中容器：宽 720px，左右两侧各留 360px，上下 padding 64px
  • 把正文用 text/reader-body 样式写进去（Georgia · 20px · line-height 36px · #2A2520）
  • 段落之间 gap: 28px
  • 在需要标注的词上叠放 InlineAnnotation/Underline component
让正文"像书"的关键：宽度不超过 720px，行高一定要 1.7 以上，背景要暖，字号不能小。这三个是最核心的。
Step 4

右侧解释面板（静止状态 = 隐藏）

右侧面板（x=1120, y=48, w=280, h=976） bg=#FFFDF8 border-left: 1px · #E4D8C8 （未点词时：空白 / 浅灰提示文字） "Tap an underlined word to see its meaning." （点词后显示） ┌──────────────────────────┐ │ concede │ 词 │ 承认，尤其是不情愿地承认 │ 释义 │ ─────────────────────── │ │ ORIGINAL SENTENCE │ label │ "He conceded that the │ 原句 │ argument was sound." │ │ ─────────────────────── │ │ severity: medium │ badge └──────────────────────────┘

做两个版本，用 Figma 的 Variants 功能区分 state=empty 和 state=active：

  1. 先做两版 Frame（empty / active）
  2. 全选 → 右键 → Combine as variants
  3. 在 Screens 里拖进来，右侧面板可以切换 state
Step 5

点词浮层（Popover）版本

如果偏好浮层而不是固定右侧面板，把之前的 Popover/Annotation 放在某个被标注词的正上方或下方，模拟点击后的状态。这样正文宽度可以做到 760px，更宽敞。

Auto Layout 是你最好的朋友

每个有多个子元素的容器，都应该加 Auto Layout（⌘ Shift A）。好处：

  • 改了内容，间距自动调整
  • 可以设置 padding、gap、方向
  • 可以 "hug content" 或 "fill container" 控制尺寸

推荐插件（用 ⌘ / 搜索安装）

  • Phosphor Icons — 线条风图标，适合这个设计的气质
  • Unsplash — 可以快速填充占位图片
  • Lorem ipsum — 快速生成占位文字
  • Stark — 检查颜色对比度（无障碍）

建议的工作顺序

  1. ✅ Design System（颜色 + 字体）
  2. ✅ 基础 Components（Button, Input, Card）
  3. ➡️ Frame 03 Immersive Reader（最核心，先做好）
  4. ➡️ Frame 02 Chapter Preload
  5. ➡️ Frame 01 Setup（相对简单）
  6. 最后：精修间距、对齐、微调颜色
最重要的原则：在这个设计里，"对的感觉"是文字本身很舒适——间距够宽，背景够暖，标注够低调。先把 Frame 03 的正文排版调到你自己愿意长时间看的状态，其他一切都是配角。
